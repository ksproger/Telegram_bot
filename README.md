# # CyberInvestigator Bot

Мощный OSINT Telegram бот для сбора информации из открытых источников.

## Возможности

- 🔍 **Разведка доменов** (WHOIS, DNS, поддомены, технологии)
- 🌐 **Разведка IP адресов** (геолокация, порты, Shodan)
- 📧 **Разведка email** (Gravatar, социальные профили, утечки)
- 📞 **Разведка телефонов** (оператор, геолокация, социальные профили)

## Поддерживаемые операторы

### Россия
- MTS, Beeline, MegaFon, Tele2, Yota

### Армения  
- **Ucom**, Viva-MTS, Team Telecom

### Международные
- Определение по коду страны

## Установка на Render

1. Создайте бота через @BotFather
2. Загрузите файлы в репозиторий
3. Создайте Web Service на Render
4. Установите переменные окружения:
   - `BOT_TOKEN` - токен бота
   - `SHODAN_API_KEY` - (опционально) API ключ Shodan
   - `VIRUSTOTAL_API_KEY` - (опционально) API ключ VirusTotal
